# Security policy

## Supported versions

Security fixes are provided for the latest published minor release. Consumers
should upgrade to the latest available version before reporting an issue.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory reporting for `hynek-systems/hynek-shop-rule` and include:

- the affected package version
- a minimal reproduction
- the expected and observed impact
- any suggested mitigation

Reports will be acknowledged as soon as they have been reviewed. Confirmed
issues will be fixed in a coordinated release before public disclosure.
